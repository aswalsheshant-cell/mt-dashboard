# MT Executive Storytelling

Translate MT analytics into decisions-first, number-backed narratives that leadership
acts on — in review decks, briefs, QBRs, and channel updates.

## The MT Narrative Framework

Every leadership communication must answer four questions in order:

```
1. WHAT happened?        → State the result with a number
2. WHY did it happen?    → Identify the 1–2 primary drivers
3. SO WHAT?              → Business implication (risk or opportunity)
4. WHAT NEXT?            → One concrete recommended action
```

Never reverse the order. Never lead with the recommendation before the context.
Never list more than 3 drivers — pick the one that explains >60% of the variance.

## Voice and Tone Rules

| Do | Do not |
|---|---|
| "Reliance NSV grew ₹14.2L (+11%) in Q1 FY27, led by D-Mart pull-through" | "NSV performance was good this quarter" |
| "GM% contracted 3.2pp due to summer promo loading — reverting in Q2" | "Margins were impacted by promotions" |
| "Distribution reached 82% numeric in Tier-1 cities vs 74% target" | "Distribution is improving" |
| Use ₹L, %, pp (percentage points) as units | Vague words: "good", "strong", "significant" |
| One sentence per bullet | Multi-line bullet points |
| Active voice: "D-Mart grew" | Passive voice: "Growth was seen at D-Mart" |

## Slide Headline Writing

A great slide headline = **action verb + result + key number + period**

Examples:
- "D-Mart Leads Q1 FY27 Recovery with ₹22L NSV, Up 18% YoY"
- "Trade Spend Efficiency Improves: ₹1.8L Offtake per ₹1L Spend vs ₹1.2L Prior Year"
- "Distribution Gap Closes 6pp to 82% Numeric — Ahead of Quarterly Target"

Templates:
```
[Chain/Brand] [verb] [metric] [to value], [±delta] [vs benchmark]
[Action taken/driver] → [result with number]
[Risk/Opportunity]: [impact in ₹L or %], [timeframe]
```

## Standard MT Review Structures

### Weekly Flash (1 page / 5 bullets)

```
## MT Weekly Flash — [Week of date]

**Headline:** [One sentence. Most important development this week.]

**Primary:** [₹L billed this week vs target vs LY. Which chains moved.]
**Offtake:** [Sell-through vs baseline. Top 3 stores / SKUs.]
**Focus Area:** [Key account, promo, or issue requiring action.]
**Risk/Opportunity:** [One item. Quantified.]
**Next Week:** [One priority action + owner.]
```

### Monthly Leadership Review (5 slides)

```
Slide 1: Executive Summary
  - NSV vs Target vs LY (₹L + %)
  - GM% vs prior month
  - One key win, one key risk

Slide 2: Primary Performance (by chain)
  - Bar chart: actual vs target vs LY
  - 2 bullet commentary: driver + outlook

Slide 3: Offtake & Distribution
  - Offtake trend by key chain
  - Numeric distribution vs target (map or bar)
  - Gap analysis: where offtake < primary (inventory risk)

Slide 4: P&L Snapshot
  - GM%, Trade Spend%, Channel EBITDA% waterfall
  - MoM delta with driver

Slide 5: Actions & Outlook
  - 3 actions in progress (owner + deadline)
  - Q2 FY forecast (single number + assumption)
```

### QBR Story Arc (15-minute version)

```
Chapter 1 (3 min): Where we started — Q beginning state
Chapter 2 (5 min): What we did — actions taken, spend, activations
Chapter 3 (4 min): What the numbers say — NSV, GM%, offtake, distribution
Chapter 4 (3 min): What's next — Q+1 targets, top 2 bets, one ask
```

## Key MT Metrics Language

Use this vocabulary consistently in all communications:

| Metric | How to state it |
|---|---|
| NSV | "₹142L NSV, up ₹14L (+11%) vs prior period" |
| GM% | "GM% at 38.2%, contracted 3.2pp MoM — promo loading driven" |
| Trade Spend | "BTL at 12.8% of NSV vs 9.6% prior — summer activation investment" |
| Offtake | "Offtake value ₹118L; primary-offtake gap 17% (inventory building)" |
| Distribution | "82% numeric distribution in Tier-1 vs 74% target (+8pp)" |
| Days of Supply | "22 days of supply at Reliance vs 18-day norm — slight overbuild" |
| Market Share | "9.2% value share in Skincare at Big Basket, +0.6pp YoY" |

## Insight Escalation Rules

| Finding | Required framing |
|---|---|
| Good result vs target | State exactly how much above, attribute the driver |
| Miss vs target | State gap in ₹L and %, give one driver, give recovery action |
| Anomaly (unexpected) | Flag explicitly: "This requires attention — [reason]" |
| Known risk materializing | "As flagged in [prior review], [impact] — mitigation: [action]" |
| Unknown cause | "Root cause under investigation; preliminary read is [X]" |

## Morning Briefing Template (Daily / Weekly)

```
## MT Morning Brief — [Date]

**Yesterday's Highlight:** [One sentence — most important MT event]

**Open Actions (due this week):**
  • [Action] — Owner: [Name] — Due: [Date] — Status: [On track / At risk]

**Today's Priority:**
  [One thing that needs a decision or action today]

**Data Alerts:**
  [Any reconciliation gap, missing source file, or dashboard discrepancy]

**Market Context:**
  [One relevant external signal: competitor promo, channel policy change, etc.]
```

## Storytelling Anti-Patterns to Avoid

- **Data dump without narrative:** Never paste a table and say "see attached" — always interpret
- **Blame language:** "D-Mart didn't order" → "D-Mart off-take gap of 18% suggests inventory carryover from prior push"
- **Over-hedging:** "This might potentially indicate..." → "This indicates..." (with clear caveat if truly uncertain)
- **Missing unit:** Always use ₹L (lakhs), %, or pp — never say "numbers are up"
- **Wrong audience calibration:** VP needs the "so what"; analyst needs the "how" — know which you're writing for
