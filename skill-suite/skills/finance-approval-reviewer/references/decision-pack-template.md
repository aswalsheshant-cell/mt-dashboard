# Finance decision pack - template

Title: `Finance decisions needed - <period> - <date>`

Top line: `<n> items need Finance, <m> ready to approve, <k> blocked on source files.`

For each item:

| Field | Content |
|---|---|
| ID / item | F-xx and a plain name |
| What happened | one line with the number |
| Why | cause in plain words |
| Business impact | rupee and % of NSV / CM2 affected; what the dashboard shows meanwhile |
| Our proposal | what we would do, clearly marked a proposal |
| Evidence | file and row count, or command output |
| Finance to return | Decision, Approver, Date, Reference |

Message to Finance (short):

> Please review the attached items. For each, reply Approve / Correct / Reject with your
> name, date and reference. We will not change any number until we have all four.
> Items with no reply stay open and are shown as "pending Finance" on the dashboard.
